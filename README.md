# おとのしゃしん（spectrogram-generator）

こえを ろくおんして スペクトログラムを いんさつしよう。

キッズフェス「音声の不思議」講義用のツールです。マイクで録音（最大5秒）すると、Praat風の広帯域スペクトログラム（ガウス窓5ms・上限8000Hz・グレースケール）を表示し、そのままハガキサイズ（148×100mm / 100×148mm）のシール用紙に印刷できます。

**公開ページ:** https://keiichiyasu.github.io/spectrogram-generator/

## 使い方

1. 「● ろくおん」→ マイクにむかって はなす →「■ とめる」
2. 「いったことば」「なまえ」を入力（印刷キャプションになります）
3. 「🖨 いんさつ」→ 印刷ダイアログで用紙「はがき」を選択

## 設定

- 広帯域（5 ms）／狭帯域（30 ms）切り替え
- ダイナミックレンジ 30–90 dB（既定 70 dB）
- 前後の無音の自動カット
- 用紙の向き（ハガキ よこ／たて）

## 技術メモ

- 依存ライブラリなしの単一HTMLファイル。`index.html` をダブルクリックで開いてもオフラインで動作します
- Web Audio API で録音、自前FFT（基数2）＋ガウス窓でスペクトログラムを計算
- 動作確認用: ブラウザのコンソールで `loadTestSignal()` を実行すると母音風のデモ信号が表示されます

関連: [wave-generator](https://github.com/keiichiyasu/wave-generator)
